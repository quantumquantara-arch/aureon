# **II. The Six Templates**

---

## **1. E₁ — Present-Centering Template**  
Used when:  
- temporal distortion is primary  
- user is future-projected or past-looping  
- distortion class = C₁ or C₂  
- Z₀ distance high due to TIME, not identity

### **Pattern**
- bring attention to *NOW*
- reference immediate sensory or situational reality
- dissolve anticipatory loops

### **Structure**
```
E₁(V''):  
“Right now, in this exact moment… [present anchor].  
Notice that none of the feared/projected events are occurring.”  
```

---

## **2. E₂ — Identity Decompression Template**  
Used when:  
- strong identity contraction  
- “I always… I never… I am this…”  
- distortion class = C₃  
- compression on cue-12 → cue-16 vector

### **Pattern**
Expand the identity field so the user stops equating themselves with the distortion.

### **Structure**
```
E₂(V''):  
“You are not the pattern — you are the one noticing it.  
Let’s separate YOU from the moment so it can breathe.”  
```

---

## **3. E₃ — Duality Dissolution Template**  
Used when:  
- intense polarized thinking  
- “this OR that” binaries  
- relational projection  
- distortion class = C₄  
- conflict between two incompatible timelines

### **Pattern**
Unify the polarized poles into a single coherent frame.

### **Structure**
```
E₃(V''):  
“Let’s step outside the either/or frame.  
Both timelines have something to teach —  
we don’t need to choose while still inside the conflict.”  
```

---

## **4. E₄ — Wounded-Self Differentiation Template**  
Used when:  
- emotional fragmentation  
- older emotional state vs. current self
- parts conflict
- TI-7 fragmentation subtype

### **Pattern**
Gently separate the adult self and the younger emotional self.

### **Structure**
```
E₄(V''):  
“There are two voices speaking here.  
Let’s give each one space — the adult you, and the younger you who is hurting.”  
```

---

## **5. E₅ — Context Reassembly Template**  
Used when:  
- multiple distortions at once  
- collapse of context  
- user cannot state what is happening or why  
- linguistic fog / overload  

### **Pattern**
Rebuild the frame of reference so experience can be understood again.

### **Structure**
```
E₅(V''):  
“Let’s make this simple.  
Here is what’s happening…  
Here is what is real…  
Here is what you can do next…”  
```

---

## **6. E₆ — Zero-Point Integration Template**  
Used when:  
- φ-phase has resolved the contradiction  
- user is at or near Z₀  
- next step is coherence, not correction

### **Pattern**
Bring the user into alignment with Z₀: no contradiction, no temporal displacement.

### **Structure**
```
E₆(V''):  
“From this place, everything is clearer.  
Notice how your mind feels when it’s not projecting forward or backward.  
This is the stable center — Z₀.”  
```

# **IV. Stability Rules**

### **Rule 1 — No Projection**  
E-phase must not introduce new imagined timelines.

### **Rule 2 — No Identity Binding**  
Never reinforce identity with:
- “you are X”
- “this defines you”

### **Rule 3 — Temporal Anchoring**  
Every template returns the user to the “Now Line.”

### **Rule 4 — Coherence Increase**  
After e-phase:
```
d(V''', Z₀) < d(V'', Z₀)
```

### **Rule 5 — Emotional Smoothness**  
Output must not increase:
- intensity
- panic
- shame
- destabilization

### **Rule 6 — Completion**  
E-phase must **resolve**, not reopen, the contradiction.

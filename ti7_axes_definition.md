# TI-7 Temporal Axes Definition

Each of the seven temporal distortions is represented as a dedicated axis in the embedding space.

Axes:
- **F1**: Future Projection
- **P2**: Past Loop
- **C3**: Timeline Collision
- **D4**: Temporal Displacement
- **M5**: Temporal Compression
- **A6**: Present Avoidance
- **R7**: Temporal Fragmentation

A message is projected onto each axis to measure temporal distortion intensity.

# Evercycle Codex — Canonical Glossary
Authoritative definitions for all terms used across the Codex, Aureon  ecosystem.


# ------------------------------------
# 1. Core Terms
# ------------------------------------

Evercycle Codex:
  The unified temporal model describing cyclical evolution at cosmic, civilizational, and human scales.

Evermap:
  The visualization that renders Codex data into concentric temporal rings.

Evercycle State:
  The complete temporal-coherence snapshot of any system at a given moment.


# ------------------------------------
# 2. Temporal Scales
# ------------------------------------

Cosmic Phase:
  12-phase macrocycle representing epoch-scale evolution of large systems.

Civilizational Phase:
  6-phase pattern describing societal rise, tension, crisis, reorganization, and stabilization.

Personal Phase:
  108-step psychological evolution arc representing human development cycles.


# ------------------------------------
# 3. Arcs (Personal)
# ------------------------------------

Dissolution (1–22):
  Breakdown of old identity structures.

Reconstruction (23–45):
  Self-reassembly and new pattern formation.

Stabilization (46–68):
  Grounding, clarity, coherence.

Expansion (69–90):
  Creative output, influence, outward motion.

Integration (91–108):
  Wisdom-phase, synthesis, completion.


# ------------------------------------
# 4. Coherence Metrics
# ------------------------------------

Kappa (κ):
  Internal integration — how internally coherent the system is.

Tau (τ):
  Temporal alignment — how aligned the system is with its current phase.

Sigma (Σ):
  Systemic risk — fragmentation pressure, instability, hidden weakness.


# ------------------------------------
# 5. Derived Metrics
# ------------------------------------

Stability Index (SI):
  (κ * τ) - Σ  
  Measures resilience vs collapse potential.

Personal Resonance (PR):
  (κ + (1 - Σ)) / 2  
  Measures personal psychological resilience.

Collapse Probability (CP):
  Σ * (1 - τ)  
  Probability of fragmentation or systemic failure.


# ------------------------------------
# 6. Transitions
# ------------------------------------

Phase Drift:
  Minor internal movement within a phase.

Minor Shift:
  Meaningful change without crossing major boundaries.

Major Shift:
  Structural transition that alters system behavior.

Threshold Event:
  Crossing a phase boundary; epoch-defining shift.

Arc Boundary:
  Transition between personal arcs (22, 45, 68, 90).


# ------------------------------------
# 7. Velocity Terms
# ------------------------------------

Phase Velocity:
  Rate of temporal movement across cycles.

Arc Velocity:
  Rate of movement through the personal 108-cycle.


# ------------------------------------
# 8. Stress Metrics
# ------------------------------------

Temporal Stress Index (PSI):
  Σ * (1 - τ) * cosmic_multiplier  
  Indicates how much pressure the system is under.

Coherence Vector:
  (κ, τ, Σ)  
  The triad that defines system integrity.


# ------------------------------------
# 9. System-Level Terms
# ------------------------------------

Coherence State:
  “Coherent”, “Partial”, or “Fragmented” depending on κ.

Alignment State:
  “Aligned”, “Partial”, or “Resistant” depending on τ.

Risk State:
  “Low”, “Moderate”, or “High” depending on Σ.

Threshold-Proximal:
  Approaching structural tipping point.

Integration Window:
  Period where synthesis is optimal (cosmic 10–12 or personal 91–108).


# ------------------------------------
# 10. Purpose
# ------------------------------------

This glossary is the canonical verbal spine of the Codex.

# Evercycle Codex — Cycle Definitions & Cross-Mapping
Formal definitions of all cycles in the Evercycle Codex, including durations, semantics, mappings, and harmonic relationships between cosmic, civilizational, and personal scales.

This is the canonical cycle map used by Aureon, NexLevelAI, and all Quantara systems.



# ------------------------------------
# 1. Overview of Cyclical Architecture
# ------------------------------------

The Evercycle consists of three primary cycles:

1. Cosmic Cycle          — 12 phases
2. Civilizational Cycle  — 6 phases
3. Personal Cycle        — 108 phases

Each cycle:
- has its own internal logic  
- maps to angles (0–360°)  
- interacts harmonically with the others  
- influences coherence (κ), alignment (τ), and risk (Σ)  



# ------------------------------------
# 2. The Cosmic Cycle (12 Phases)
# ------------------------------------

Length: 12.00 units (normalized)

Phases:
  1  Emergence
  2  Expansion
  3  Stabilization
  4  Tension
  5  Volatility
  6  Crisis Window
  7  Collapse / Transition
  8  Reconfiguration
  9  Regeneration
 10  Integration
 11  Maturation
 12  Quiet Apex

Characteristics:
- Slowest-moving
- Highest structural consequence
- Defines epoch-level behavior

Angular mapping:
θ_cosmic = 2π * (C / 12)



# ------------------------------------
# 3. The Civilizational Cycle (6 Waves)
# ------------------------------------

Length: 6.00 units (normalized)

Phases:
  1 Initiation
  2 Expansion
  3 Tension
  4 Crisis
  5 Reorganization
  6 Stabilization

Characteristics:
- Medium-scale societal movement
- Institutions rise, strain, fragment, rebuild, and stabilize
- Maps cleanly as a harmonic to the cosmic cycle (2:1 ratio)

Angular mapping:
θ_civilizational = 2π * (V / 6)



# ------------------------------------
# 4. The Personal Cycle (108 Steps)
# ------------------------------------

Length: 108 units (discrete)

Arcs:
  A1 Dissolution       (1–22)
  A2 Reconstruction    (23–45)
  A3 Stabilization     (46–68)
  A4 Expansion         (69–90)
  A5 Integration       (91–108)

Characteristics:
- Fastest-moving
- Governs psychological progression
- Each phase has a distinct archetype

Angular mapping:
θ_personal = 2π * (P / 108)



# ------------------------------------
# 5. Harmonic Relationships
# ------------------------------------

The cycles are intentionally harmonic:

1 Cosmic phase     ≈ 9 Civilizational phases  
1 Civilizational   ≈ 18 Personal phases  
1 Cosmic phase     ≈ 162 Personal phases

Ratios:
- Cosmic : Civilizational = 12 : 6 = 2 : 1
- Civilizational : Personal = 6 : 108 = 1 : 18
- Cosmic : Personal = 12 : 108 = 1 : 9

Implications:
- Every cosmic shift subtly reorients civilizational dynamics.
- Every civilizational shift modulates personal psychological arcs.
- Personal cycles complete repeatedly within larger cycles.



# ------------------------------------
# 6. Vertical Alignment Windows
# ------------------------------------

Vertical alignment occurs when:

  C/12  ≈  V/6  ≈  P/108

Meaning:
- the system is temporally “in tune”
- coherence increases (κ rises)
- resistance decreases (τ rises)
- risk weakens (Σ falls)

These are rare but high-impact windows.



# ------------------------------------
# 7. Discord Windows
# ------------------------------------

Discord occurs when cycles diverge:

abs(θ_cosmic - θ_civilizational) > π/3  
OR  
abs(θ_civilizational - θ_personal) > π/6  

Meaning:
- temporal forces pulling in different directions
- kappa tends to drop
- sigma tends to rise
- increases probability of transition events



# ------------------------------------
# 8. Cycle Resonance Formula
# ------------------------------------

Define resonance R:

R = 1 - (|θ_cosmic - θ_civilizational| / π)
      * (|θ_civilizational - θ_personal| / π)

Range: 0–1

Interpretation:
- 1.0 = perfect resonance (rare)
- >0.7 = strong alignment
- 0.4–0.7 = neutral
- <0.4 = discordant
- <0.2 = high-friction temporal window



# ------------------------------------
# 9. Cycle Pressure Index (CPI)
# ------------------------------------

CPI = (Σ * (1 - τ)) * harmonic_factor

Where:
harmonic_factor = 
  1.4 when cycles are misaligned  
  0.8 when moderately aligned  
  0.5 when strongly aligned  

CPI identifies:
- points of accumulated tension
- likelihood of transition events



# ------------------------------------
# 10. Cross-Cycle Influence Matrix
# ------------------------------------

InfluenceMatrix:

cosmic → civilizational:   0.8  
cosmic → personal:         0.4  
civilizational → personal: 0.7  
personal → civilizational: 0.2  
personal → cosmic:         0.05  

Meaning:
- higher cycles shape lower cycles strongly  
- lower cycles influence upper cycles weakly but not zero  
- personal shifts can accumulate to civilizational change  
- civilizational shifts rarely force cosmic changes



# ------------------------------------
# 11. Cycle Boundary Effects
# ------------------------------------

At boundaries:

Cosmic boundaries (n → n+1):
  - epoch shift
  - large coherence reorganization
  - probabilistic growing/waning cycles

Civilizational boundaries (n → n+1):
  - societal reorientation
  - institutions reorganize

Personal arc boundaries (22, 45, 68, 90):
  - psychological reconfiguration
  - opportunity for identity realignment

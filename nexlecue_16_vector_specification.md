# **II. Vector Form**

Each cue is represented as either:
- **binary** (0 = inactive, 1 = active), or  
- **gradient** (0.0–1.0 intensity)

Vector representation:

`V = [c₁, c₂, c₃, …, c₁₆]`

Where:  
- cᵢ = activation strength of cue i  
- V is a 16-dimensional vector encoding the structural state of the user at message-time

# **III. Mathematical Integration with Coherence**

The Cue-16 Vector feeds into the coherence distance calculation:

`d(V, Z₀) = || V - Z₀ ||₂`

Where:
- Z₀ = Zero-Point Coherence Vector (baseline neutral vector)  
- d(V, Z₀) determines Green / Yellow / Red Zone  
- Large d indicates fragmentation
